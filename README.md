# mi amour ♡

曾沛慈影像珍藏馆。369 张照片：舞台 117、日常 135、角色 33、画报与穿搭 84。

网站通过 GitHub Pages 发布，源码与全部照片均在本仓库。

所有原始文件保持字节一致，HEIC 额外提供同分辨率无损 WebP 浏览文件。画报、索引和灯箱使用完整分辨率图片；页面显示自然标题与编号，不显示原始文件名。

修改页面：`index.html`；样式：`amour.css`；交互：`amour.js`；照片目录：`pets/photos.json`。

本地预览：`python -m http.server 4173`。心动与访客自行导入的照片仅保存在访客的当前浏览器；内置 369 张图片对所有访客可见。

非官方个人影像收藏。图片不包含在代码许可声明内。

首页 CD 相框支持上一张/下一张循环切换，点击当前封面可打开对应灯箱。已移除原 No.273、No.280、No.281，保留其余档案编号，便于后续定位。

顶部迷你 CD 播放器内置 21 首音乐，支持播放/暂停、切歌、歌单选择、拖动进度、音量与列表/单曲循环。首次进入需点击播放，不自动下载整份歌单。播放器记住歌曲与音量偏好；音频在 `music/` 中保持原始文件，清单为 `music/playlist.json`。
